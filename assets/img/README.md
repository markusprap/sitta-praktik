# Cover Images

Folder ini untuk menyimpan gambar sampul buku bahan ajar.

## Format Gambar
- Format: JPG atau PNG
- Ukuran maksimal: 2 MB
- Resolusi rekomendasi: 400x600 px (ratio 2:3)

## Nama File
Sesuaikan dengan kode buku, contoh:
- `pengantar_komunikasi.jpg` untuk ASIP4301
- `manajemen_keuangan.jpg` untuk EKMA4216
- `kepemimpinan.jpg` untuk EKMA4310
- `mikrobiologi.jpg` untuk BIOL4211
- `paud_perkembangan.jpg` untuk PAUD4401

## Default Image
Jika gambar tidak tersedia, sistem akan otomatis menggunakan `default.jpg`
